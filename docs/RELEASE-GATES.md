## 2. 云函数与模型

将 `miniprogram/cloudfunctions/noticeService` 上传并安装依赖。别名 `evalService` 采用相同内容。`wx-server-sdk` 锁定4.0.2，服务运行时与云函数超时在控制台确认；建议云函数超时不小于30秒。客户端请求超时25秒，模型单次等待14秒后显式回退规则。超时不会取消供应商已经发出的计算请求，费用仍以平台记录为准。

环境变量：

```text
BANLI_FORMAL_ENABLED=false
BANLI_OPERATOR_NAME=实际运营主体名称
BANLI_PRIVACY_CONTACT=真实有效的隐私联系渠道
BANLI_AI_MODEL=控制台已开通的模型标识
```

参考默认模型为 `hy3`。**当前模型开通、额度、响应格式和真实收费状态未实测**。按控制台选择已可用模型；不得把规则回退当成模型联调成功。示例AI限每个微信身份每天12次，正式AI60次；这是预算保护，未替代全局费用告警或防刷系统。

## 3. 数据库与索引

新建集合：`banli_memberships`、`banli_classes`、`banli_teachers`、`banli_consents`、`banli_children`、`banli_observations`、`banli_preparations`、`banli_analyses`、`banli_budgets`。

**所有集合禁止客户端直接读写；仅由服务端云函数和授权管理员访问。** 在实际控制台确认该环境采用的安全规则格式，不可混用Web版与微信云开发语法。至少用一个未授权微信账号直接读/写集合，确认被拒绝。

观察查询涉及 tenant_id、class_id、deleted、child_ids、observed_at、_id。按实际查询创建所需组合索引，测试包含一个孩子且跨越80条以上的记录。当前名单读取支持单班100名以内；试点班级不得超过该范围。每次分页50条，汇总最多1000条，超出须缩小日期范围。

## 4. 配置正式班级身份

`accessInfo` 只返回当前微信身份的 SHA-256 授权识别码（actorKey）。它不是密码，也不能代替用户身份。由管理员核实教师身份后，在 `banli_memberships` 建立 `_id=actorKey` 的记录。不要让用户提交的教师姓名直接决定权限。

下面仅展示字段结构，名称及编号均为虚构，不能充当真实授权：

```json
{
  "banli_classes": {"_id":"class-example","tenant_id":"school-example","name":"示例班","kindergartenName":"示例园所"},
  "banli_teachers": {"_id":"teacher-example","tenant_id":"school-example","class_id":"class-example","name":"示例教师"},
  "banli_memberships": {"_id":"由实际微信身份生成的actorKey","status":"active","privacyReady":true,"tenantId":"school-example","classId":"class-example","teacherId":"teacher-example","canManageChildren":true},
  "banli_consents": {"_id":"consent-example","tenant_id":"school-example","class_id":"class-example","status":"active","reference":"园所内部授权凭据编号","displayName":"示例幼儿","observe":true,"media":false,"ai":false,"expiresAt":"2027-07-01T00:00:00Z"}
}
```

`privacyReady=true` 只是管理端开关；必须对应已经履行的告知、授权和规则建设，不能当作授权材料本身。由班级负责人输入有效授权编号添加幼儿；默认不收精确生日、性别、监护人手机号。监护人授权凭据由园所受控保存，公开仓库只保留虚构示例。

同班已授权教师可读观察；只有记录教师可修改/删除。多园、多班、管理员后台和家长自助端尚未扩展，不能宣传成完整园务平台。

- [ ] 实测 `getTempFileURL`、照片/视频显示、音频播放、报告照片下载，以及对应合法域名。
- [ ] 本版前端限制每条9个附件、选中附件20MB以内；它不构成服务端文件内容/配额校验。上传与内容安全扫描、恶意文件处理、全局存储预算仍需补齐后才可广泛开放。
