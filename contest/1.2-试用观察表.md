# 班里手记：一轮小范围试用

建议先邀请3—5位教师，在虚构或已充分授权的去身份情境中完成同一组任务。以下均是试用设计，尚未取得真实结果。

| 任务 | 观察什么 | 怎样留下证据 |
|---|---|---|
| 无辅助记录一件小事 | 从打开到留下实录的时间、误触、遗漏 | 起止计时、教师口述；不用儿童录像 |
| 回看一条线索 | 是否理解AI/规则来源、是否能找到对应片段 | 原建议与教师修改并置，解释修改原因 |
| 不采纳自动线索 | 是否知道可以只留实录，是否感到被迫完成评价 | 点击路径、简短访谈 |
| 选择日期并导出 | 能否找到完整记录、识别未确认内容、判断缺图 | 导出文件检查；超过80条的虚构样本 |
| 断网及附件失败 | 是否区分本机草稿、云端成功和附件未完成 | 手机提示截图，重试后的记录数 |
| 撤回授权后再访问 | 是否停止读取，旧文件和临时链接如何处理 | 双账号受控测试记录 |

每个任务记录：完成/未完成、实际耗时、遇到的问题、是否需要指导。与教师原有流程使用相同任务比较，记录样本量和条件；不能把自评“感觉更快”写成精确减负百分比。

核心访谈只问三件事：哪一步最自然；哪一步打断了你；这份回看有没有帮助你更理解孩子。先修重复出现的问题，再决定是否扩展功能。
