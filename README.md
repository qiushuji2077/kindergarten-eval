# 班里手记

**留住一个瞬间，慢慢读懂一个孩子。**

面向幼儿园教师的**原生微信小程序**：保存具体实录，回看可能的观察线索，由教师确认自己的理解，再整理为观察汇总。

核心流程：**当时记下 → 有空回看 → AI 提供辅助线索 → 教师确认或调整 → 形成观察汇总。**

## 这次真正改变了什么

- **记录优先**：不在输入时自动调用 AI。可先保存原话，稍后回看；照片、视频与录音仍可作为附件。
- **教师确认**：原话、辅助线索、教师判断分开。采纳、调整、仅留实录三种选择；文字改变后清除旧分析状态。
- **证据边界**：模型只能从给定方向中选择，并提供逐字可核对的输入片段。模型故障时明确显示规则提示。
- **报告边界**：未确认的辅助解释不进入正式解读。不生成发展等级。
- **真实与示例隔离**：示例记录存本机；自由输入不发模型。
- **权限前置**：服务端从微信身份取得园所、班级、教师权限；监护人授权单独记录。
- **筛选一致**：手记页的孩子、日期筛选与回看导出使用同一套读取范围，分页在过滤之后。
- **视觉**：暖白、深绿、麦色，正文优先，文字式底部导航。

## 专业边界

当前七个方向为本项目整理的观察提示，**并非《3—6岁儿童学习与发展指南》逐字原文、完整指标体系或标准化发展量表**。录音附件与输入法语音转文字不是同一功能，本版不会把录音自动变成文字。
