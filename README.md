# 班里手记

**留住一个瞬间，慢慢读懂一个孩子。**

面向幼儿园教师的原生微信小程序：保存具体实录，回看可能的观察线索，由教师确认自己的理解，再整理为观察汇总。

## 当前状态

此分支是 **1.2.0-review 评审版**，从原有 1.1.0 独立改造。代码修改不等于微信平台已部署或已通过审核。真实班级默认关闭；示例体验可先在开发者工具中走通。原 `main` 保持不变。

旧 `client/`、`server/` 与旧版 `kg_*` 数据结构属于历史网页原型；本次没有为它们增加权限控制，也不应将旧网页后端直接开放给真实儿童数据。新页面只调用 `banli-*` 工具和经过授权校验的 `noticeService`。云端曾部署的 `evalService` 也须升级为本分支同版本或下线，避免遗留入口。

## 这次真正改变了什么

- **记录优先**：不在输入时自动调用AI。可先保存原话，稍后回看；照片、视频与录音仍可作为附件。
- **教师确认**：原话、辅助线索、教师判断分开。采纳、调整、仅留实录三种选择；文字改变后清除旧分析状态。
- **证据边界**：模型只能从给定方向中选择，并提供逐字可核对的输入片段。模型故障或结果无效时，明确显示规则提示；不伪装为AI成功。
- **报告边界**：未确认的辅助解释不进入正式解读。不自动生成发展等级，不在导出时偷偷补上判断。阶段回看由教师编辑，支持汇集已确认的教师摘记。
- **真实与示例隔离**：示例记录存本机，只有内置虚构场景可发送云端演示AI；自由输入不发模型。正式请求失败不会降级成演示成功。
- **权限前置**：服务端从微信身份取得园所、班级、教师权限；监护人授权单独记录，观察、媒体、AI范围分别校验。
- **可靠保存**：本机草稿与云端状态明确分开，重复保存有幂等编号，修改有版本冲突检查，附件失败可重试，日期过滤在分页前完成。
- **视觉收束**：暖白、深绿、麦色，正文优先，文字式底部导航，无评分、排名、奖章或装饰性仪表盘。

## 先运行示例

用微信开发者工具导入本仓库的 `miniprogram/` 目录。配置保留原AppID，开发者必须有该号权限。先点“先用一个示例走一遍”，不要输入真实儿童资料。

即使云函数尚未升级，示例仍可保存本机记录、展示规则线索和生成Word。真实AI示例需要部署当前 `noticeService`、创建预算集合并开通所选模型；模型调用失败必须显示规则来源。

```bash
# 项目根目录，Node.js 22；测试无需安装依赖
npm test
npm run check
node scripts/build-preview.js
```

`preview/index.html` 是同版WXML/WXSS生成的**浏览器排版预览**，仅用于切换页面看版式，不能替代微信真机测试。

## 专业边界

当前七个方向为本项目整理的观察提示：同伴交往、情绪表达、倾听与表达、探究与尝试、数量与空间、生活自理、感受与表达。它们与五领域建立索引联系，**并非《3—6岁儿童学习与发展指南》逐字原文、完整指标体系或标准化发展量表**。旧代码中的固定COA级别退出当前流程。要恢复官方条目逐字引用，应先完成来源、版本、原文与年龄段的逐项校核，再作为独立内容升级。

姓名替换和模式识别只能降低可识别性，无法保证彻底匿名。教师可在发送前检查文本，但仍需合法授权、处理规则、供应商条款和园所治理。云端数据清理、备份保留与外发文件撤回不会被一个隐私弹窗自动解决。
